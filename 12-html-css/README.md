# 💻 HTML, CSS и работа с макетом

Учебный проект по веб-вёрстке, который последовательно дорабатывался по мере изучения HTML, CSS и работы с макетом в Figma.

## Этапы работы

### 1. Базовая HTML-структура

- применение HTML-тегов;
- создание базовой структуры страницы;
- работа со ссылками, изображениями, списками и текстовыми элементами;
- соблюдение базового HTML-кодстайла.

[Исходный код](./01-html-basics/)

### 2. Создание сайта с CSS-оформлением

- подключение CSS;
- работа с блочной моделью;
- использование классов;
- организация структуры CSS-файлов;
- оформление HTML-страницы.

[Исходный код](./02-css-layout/)

### 3. Оформление страницы с помощью CSS

- применение CSS-свойств для оформления страницы;
- работа с отступами;
- оформление блоков и элементов;
- работа с изображениями и фоном.

[Исходный код](./03-css-styling/)

### 4. Дизайн и верстка в Figma

- работа с макетом в Figma;
- экспорт изображений и графических элементов;
- создание контейнера страницы;
- вёрстка страницы по макету;
- работа с HTML и CSS.
