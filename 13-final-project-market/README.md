# 🧪 Итоговый проект № 1 — тестирование Market

Учебный проект по тестированию сайта `market.sedtest-tools.ru`.

## Что было выполнено

- Анализ сайта и выделение ключевых объектов.
- Применение различных техник тест-дизайна для выбора оптимальных методов тестирования.
- Составление чек-листов и тест-кейсов для проверки функциональности.
- Проведение тестирования и фиксация найденных багов.

## Результат

- Создана тестовая документация, включающая чек-листы, тест-кейсы и отчёты по найденным багам.
- Применены различные техники тест-дизайна.
- Проведено тестирование сайта с выявлением ошибок и составлением отчётов.
