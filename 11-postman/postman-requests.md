# 📡 Запросы в Postman

## DummyAPI

**Тестовая площадка:** `dummyapi.io`

### 1. Создание пользователя

**Метод:** `POST`

```text
https://dummyapi.io/data/v1/user/create
```

---

### 2. Поиск пользователя по id

**Метод:** `GET`

```text
https://dummyapi.io/data/v1/user/{id}
```

---

### 3. Поиск списка пользователей до 5

**Метод:** `GET`

```text
https://dummyapi.io/data/v1/user
```

---

### 4. Редактирование пользователя

**Метод:** `PUT`

```text
https://dummyapi.io/data/v1/user/{id}
```

---

### 5. Удаление пользователя

**Метод:** `DELETE`

```text
https://dummyapi.io/data/v1/user/{id}
```

---
